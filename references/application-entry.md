# 지원서 입력 보조 — 요청이 있을 때만

사용자가 브라우저 연동 도구로 채용 사이트의 지원서 입력을 맡기면 읽는다. 원고 작성·평가 단계에 자동으로 붙이지 않는다.

## 경계

- 로그인, 본인 인증, 비밀번호, 동의 체크, 서약, 최종 제출은 사용자가 한다. 사용자가 그 행동을 명시적으로 맡긴 경우에도 실행 직전에 무엇을 누르는지 한 번 확인한다.
- 사용자가 준 이력서·증명서·경험 기록에 있는 값만 넣는다. 없는 값은 비워 두고 목록으로 알린다. 선택지에 정확한 항목이 없으면 가장 가까운 선택과 그 이유를 알리고 사용자가 고를 수 있게 한다.
- 지원 자격·우대 판단(지역 인재, 어학 인정 범위 등)은 일반 지식이 아니라 해당 공고 원문의 정의로 확인한다.
- 임시저장은 사용자 선호를 따른다. 정해지지 않았으면 긴 입력을 마친 뒤 저장을 권하고, 화면에 세션 만료 시간이 보이면 알린다. 초기화·삭제처럼 입력을 지우는 버튼은 누르지 않는다.

## 입력

- 원고를 넣기 전에 실제 칸의 문항과 글자 수 계산 방식을 확인한다. 넣은 뒤 화면의 글자 수와 줄바꿈을 원고와 대조한다. 실제 칸의 문항이 준비한 문항과 다르면 입력을 멈추고 알린다.
- 필수 칸만 채우고 멈추지 않는다. 사용자 자료에 근거가 있는 선택 칸(자격, 수상, 활동, 활용 능력, 첨부 등)도 채운다. 시간을 이유로 비우지 않으며, 비운 칸은 이유와 함께 보고한다.
- 블라인드 안내가 있으면 학교명 같은 금지 정보를 활동·경력 칸에서도 확인한다. 제출 서류 안내(파일 형식, 묶음, 개인정보 가림)를 따른다.
- 선택 동의를 하지 않으면 입력한 선택 항목이 제출되지 않는 사이트가 있다. 동의 안내문을 읽고 그 영향을 사용자에게 알린다.
- 칸을 옮길 때마다 앞 칸이 저장됐는지 확인한다. 저장되지 않은 칸에 이어서 입력하면 값이 섞인다.

## 마무리

제출 직전에 입력값을 다시 읽어 원고·자료와 대조하고 빠진 칸, 임의로 고른 값, 확인이 필요한 항목을 짧게 보고한다. 제출 여부와 시각은 사용자가 확인한 경우에만 기록한다.
